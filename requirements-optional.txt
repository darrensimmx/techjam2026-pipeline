# requirements-optional.txt -- the Layer 3 seams ONLY.
#
# READ THIS BEFORE INSTALLING ANYTHING HERE.
#
# 1. The graded path never needs any of it. `src/` is standard library only by
#    design -- json, re, sqlite3, dataclasses, typing. That is a deliberate
#    submission decision, not an accident of the build: `submission_rules.md`
#    reserves the organizer's right to run the submission under CPU, memory,
#    timeout and network restrictions, so fewer dependencies is less that can
#    fail when it counts. The agent must score with NOTHING from this file
#    installed, and that is the configuration we ship.
#
# 2. `requirements.txt` stays empty (comments only) DELIBERATELY. Do not move
#    anything from here into it. If a layer below is ever approved and turned
#    on, that is a submission-level decision with a disclosure attached -- not
#    a line edit.
#
# 3. Installing any of these changes NOTHING on its own. Every optional layer
#    is gated by a flag that is False in the source, and each loader checks the
#    flag BEFORE it checks for the dependency. A pip install with the flag
#    still False leaves the null implementation in place, byte for byte.
#
#      src/semantic.py    TIER2_ENABLED       = False   Tier 2 semantic fallback
#      src/llm_rerank.py  LLM_RERANK_ENABLED  = False   LLM ranking escalation
#      src/rerank.py      load_reranker(enabled=False)  cross-encoder rerank
#
#    Every entry is commented out because no checkpoint and no model has been
#    chosen -- see docs/todo.md items 1, 3 and 4. Pinning a version here would
#    imply a decision nobody has made.
#
# 4. Nothing here is importable except through `src/optional_deps.try_import`,
#    which returns None on ANY failure -- including a package that raises at
#    import time, which a narrow `except ImportError` would miss.
